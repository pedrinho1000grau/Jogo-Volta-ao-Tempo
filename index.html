Ano 2189. Uma falha misteriosa desestabilizou a linha temporal. Acontecimentos históricos estão desaparecendo e o futuro tornou-se imprevisível.

Você foi convocado para pilotar a Cronos, uma máquina experimental capaz de atravessar épocas. Explore diferentes períodos, descubra acontecimentos históricos e escolha como sua história vai se desenrolar.

MANUAL DE NAVEGAÇÃO

Como jogar

  • Leia o desafio de cada época histórica.
  • Escolha uma das três alternativas disponíveis.
  • Suas escolhas podem avançar, saltar ou retornar para outra etapa.
  • Algumas escolhas permitem mudar de narrativa.
  • Decisões perigosas podem provocar Game Over.
  • Existem dois finais possíveis para a aventura.

Dica: pense nas consequências de cada decisão e observe as pistas históricas.
